# MindustrySpritesFullIconProcessingTool

A simple Mindustry texture tool, mainly used for the creation of full icons, among other purposes.

The latest version is: [V1.4.5](https://github.com/CNFNMBlcokyLemon/MindustrySpritesFullIconProcessingTool/releases/tag/Available_V1.4.5)!

Primary Writing and Concept: CNFNM, DeepSeekAI

Assisted Development and UI Design: DeepSeekAI

Supported System: Windows10

Made with Dev-C++

一个简易的Mindustry贴图工具, 主要用于full贴图的制作等.

目前最新版本为 [V1.4.5](https://github.com/CNFNMBlcokyLemon/MindustrySpritesFullIconProcessingTool/releases/tag/Available_V1.4.5)!

Changelog:

V1.4.5: [

Major Update!!!

Important Notice: Compiling the entire program now requires a complete MinGW64!!!

1. Added Simplified Chinese.

2. Added drag-and-drop functionality to all image file selection areas (unreleased V1.3.5).

3. Optimized window flickering using double buffering (compared to unreleased V1.3.9) and fixed double ghosting in the preview area.

4. Removed keyboard interaction in the preview area (compared to unreleased V1.4.0, greatly improving convenience) and replaced it with mouse drag and scroll wheel zoom.

5. Added feature: In the Weapons List, left-clicking an entry once will select it and display it and its mirrored image in the preview area with a red outline. Right-clicking the selected entry will deselect it and remove the red highlight in the preview area (to help users confirm their additions or edits when there are many weapons) (unreleased V1.4.2).

6. Fixed deselection bug in the Weapons List (unreleased V1.4.3).

7. Outline color RGB options now support real-time conversion between decimal and hexadecimal. Added two buttons to reset to the original outline color. Additionally, after changing the unit main texture's outline file, the outline color of all weapons will automatically follow the unit's main outline color (unreleased V1.4.4).

8. Added feature: When exporting images, a JSON file will also be exported in the output directory, containing relevant information for the corresponding weapon (unreleased V1.4.1).

9. Fixed garbled Chinese issue in the corresponding JSON files (unreleased V1.4.2).
